[RU] Инсталляция ------------------------------------------------------------------------------------------------------------------------------------------------

Поставляемый инсталляционный пакет содержит два исполняемых файла:
                FBInstall.exe – система управления базами данных (СУБД) FireBird 2.0;
                AluRoll_Install.exe – непосредственно программа AluRoll.

Последовательность инсталляции должна быть следующей:

1. Инсталлировать СУБД FireBird 2.0, запустив файл текущего поставляемого инсталляционного пакета – FBInstall.exe. Если предполагается, что в локальной сети с программой AluRoll будут работать несколько пользователей, то СУБД FireBird необходимо инсталлировать  только на один компьютер сети, так называемый компьютер-сервер, на котором будет размещаться единственная (для данной сети) база данных программы AluRoll. 

2. Деинсталлировать старую версию программу AluRoll, если она была инсталлирована на данном компьютере ранее.

3. Инсталлировать программу AluRoll, запустив файл текущего поставляемого инсталляционного пакета - AluRoll_Install.exe. При инсталляции программы можно выбирать,  какую составляющую программы нужно инсталлировать на данном компьютере: либо клиентскую (опция “Клиент”), либо серверную (опция “База данных”). 





[EN] Installation ------------------------------------------------------------------------------------------------------------------------------------------------

The installation package consists of two executable files:
                FBInstall.exe, FireBird 2.0 DBMS;
                AluRoll_Install.exe, AluRoll program.

To install the program, proceed as follows:

1. Install FireBird 2.0 DBMS, run FBInstall.exe from the delivered installation package. If it is expected that several users will work with AluRoll in a local network, so FireBird must be installed on one computer only (the server computer) where should be installed only one (within the network) database for AluRoll program. 

2. Uninstall an old AluRoll version on this computer if it was installed on this computer before.

3. Install AluRoll, run AluRoll_Install.exe from the delivered installation package. During the installation, you can choose the program part to be installed on this computer: for client (Client option) or server program part (Database option). 





[DE] Installation -----------------------------------------------------------------------------------------------------------------------------------------------

Das gelieferte Installationsdatenpaket enthält zwei ausführbare Dateien:
             FBInstall.exe – das FireBird 2.0 - Datenbankmanagementsystem;
             AluRoll_Install.exe – das AluRoll - Programm.

Installationsreihenfolge: 

1. Das FireBird 2.0 - Datenbankmanagementsystem installieren. Dafür ist die FBInstall.exe - Datei zu starten. Wird das AluRoll - Programm im lokalen Netzwerk durch mehrere Benutzer betrieben, so ist das FireBird 2.0 - Datenbankmanagementsystem nur an einem Netz-PC (sog. PC-Server) zu installieren, wo die (für dieses Netz) einzige Datenbank von AluRoll installiert wird.   

2. Ist an dem PC die ältere AluRoll - Version installiert, ist diese zu deinstallieren.

3. Das AluRoll - Programm installieren. Dafür ist die AluRoll_Install.exe - Datei zu starten. Bei der Programminstallation ist es möglich, das notwendige Bestandprogramm, entweder das Kunden- (Option Client) oder das Server-Programm (Option Datenbank), zu wählen.





[FR] Installation ------------------------------------------------------------------------------------------------------------------------------------------------

Le paquet d’installation livré contient deux fichiers exécutables:
                FBInstall.exe – système de gestion des bases de données (DBMS) FireBird 2.0;
                AluRoll_Install.exe – programme AluRoll.

L’ordre de l’installation doit être le suivant:

1. Installer DBMS FireBird 2.0, en démarrant le fichier du paquet d’installation livré – FBInstall.exe. Si on prévoit le travail avec le programme AluRoll dans le  réseau local de plusieurs utilisateurs, il ne faut qu’installer DBMS FireBird sur l’un des ordinateurs du réseau, dit ordinateur serveur, sur lequel sera installée l’unique (pour ce réseau) base de données du programme AluRoll. 

2. Désinstaller l’ancienne version du programme AluRoll, si elle a été installée sur cet ordinateur autrefois.

3. Installer le programme AluRoll, en démarrant le fichier du paquet d’installation livré - AluRoll_Install.exe. Lors de l’installation du programme vous pouvez choisir les composants du programme qu’il faut installer sur cet ordinateur: client (option “Client”) ou serveur (option “Base de données”).
