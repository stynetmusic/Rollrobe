# Rollrobe

Офлайн-калькулятор сметы рольставен. Это не AluRoll и не автоподбор комплектации: программа не выбирает короб, вал, привод и ламели. Позицию вы ищете сами, ставите количество и свою цену. Итог — сумма строк.

Ширина и высота — поля заказа. В деньги они не входят. Наценки нет.

## Запуск на Mac

Нужен Python 3.11 или новее и Tk (он есть в обычной сборке Python).

```bash
cd /Volumes/T9/projects_code/Rollrobe
python3 -m pip install -r requirements.txt
python3 main.py
```

На этом компьютере команды `python` нет, только `python3`. Если у вас `python` уже указывает на Python 3, сработает и `python main.py`.

Запускать можно из любой папки: прайсы и база ищутся рядом с `main.py`, а не в текущем каталоге.

```bash
python3 /Volumes/T9/projects_code/Rollrobe/main.py
```

При первом запуске, если базы ещё нет или в ней не хватает прайса, программа читает три файла ПГИ из своей папки:

| Файл | Что делает |
| --- | --- |
| `ПГИ-06-12-2024.xlsx` | импорт, этот прайс становится активным |
| `ПГИ-16.09.2024.xlsx` | импорт, не активный |
| `ПГИ-16.09.2024-42.xlsx` | импорт, не активный |

`Test.xlsx` не импортируется: это формат `@AR-NetPriceList`, не ПГИ. `Readme.txt` в папке — инструкция AluRoll, к Rollrobe не относится.

База: `data/rollrobe.sqlite` рядом с программой. Её можно копировать вместе с папкой. Сети, учёток и сервера нет.

## Как считать смету

1. На экране **Смета** введите код, имя или цвет. Поиск идёт по активному прайсу.
2. Позиции с ценой 0 скрыты. Их показывает переключатель **Показывать без цены**.
3. Укажите количество (дробное, шаг 0,01) и нажмите **В смету** или Enter.
4. Цена копируется в строку сметы. Дальше её правят только в этой строке: двойной щелчок по количеству или цене. Правка прайса уже сохранённые сметы не меняет.
5. Итог — сумма строк. Сумма строки = количество × цена, округление до 0,01. Итог равен сумме этих строк.

Шапка сметы: номер, дата, клиент, объект, ширина мм, высота мм, комментарий.

Кнопки: новая смета, открыть, сохранить, дублировать, экспорт этой сметы в xlsx, удалить строку.

## Прайс

На экране **Прайс** выбирается активный прайс из импортированных. Поиск тот же. **Моя цена** правится двойным щелчком и сразу пишется в базу. **Цена файла** остаётся той, что пришла из xlsx.

Повторный импорт файла с тем же именем обновляет цену из файла и добавляет новые артикулы. Если вы уже меняли свою цену, она не затирается. Кнопка **Заменить мои цены ценами из файла** как раз затирает все свои цены активного прайса. **Сбросить позицию к файлу** делает это для одной строки.

Импорт ждёт шапку ПГИ: в первой ячейке `AluRoll`, данные с 4-й строки.

Колонки файла, подписей в нём нет:

1. код артикула
2. флаг, программа его не читает
3. коммерческое имя
4. цвет (`-`, `00`, `02`, `101` и так далее)
5. флаг, не читается
6. цена с десятичной запятой, например `2296,26`
7. код единицы: `0`, `2`, `3` или `4`

Строки с ценой 0 тоже попадают в базу.

Экспорт прайса — отдельная читаемая таблица (код, имя, цвет, единица, цена файла, моя цена). Это не файл ПГИ, обратно его импортировать не нужно. Исходные xlsx программа перезаписать не даст.

## Настройки

Подписи единиц по умолчанию: `ед. 0`, `ед. 2`, `ед. 3`, `ед. 4`. Их можно переименовать. Код единицы при этом не меняется. Здесь же видно, какой прайс активен: переключение сразу записывается, как и на экране прайса.

## Клавиши

Работают и Ctrl, и Cmd, в том числе при русской раскладке:

| Клавиши | Действие |
| --- | --- |
| Ctrl+F или Cmd+F | поиск |
| Ctrl+S или Cmd+S | сохранить смету (на настройках — подписи) |
| Ctrl+N или Cmd+N | новая смета |
| Enter | добавить выбранную позицию в смету |
| Delete | удалить строку сметы (на Mac сработает и клавиша Delete, и Backspace, когда фокус в таблице) |

Двойной щелчок по количеству или цене в смете — правка. Двойной щелчок по «Моя цена» в прайсе — правка цены.

## Сборка Windows exe

Exe собирается только на Windows. На Mac эту сборку не запускать: PyInstaller сделает программу под ту систему, на которой его запустили, и macOS-сборка не будет exe.

На Windows, в папке программы, где лежат три xlsx ПГИ:

```bat
py -3 -m pip install -r requirements.txt pyinstaller
py -3 -m PyInstaller --noconfirm --windowed --name Rollrobe --collect-all customtkinter --add-data "ПГИ-06-12-2024.xlsx;." --add-data "ПГИ-16.09.2024.xlsx;." --add-data "ПГИ-16.09.2024-42.xlsx;." main.py
```

Готовая папка: `dist\Rollrobe\`. Запуск: `dist\Rollrobe\Rollrobe.exe`.

Рядом с exe появится `data\rollrobe.sqlite`. Три прайса при такой команде упакованы внутрь сборки и подхватятся при первом запуске. Можно и не паковать их, а просто положить xlsx рядом с exe — программа смотрит оба места.

Это не установщик. Отдельный exe-инсталлятор не нужен и в проект не входит.
